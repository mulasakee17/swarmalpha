# Historical code, experiments, and documentation

This subtree is physically separated from the current research surface.
Read it only for a scoped historical audit, compatibility fix, or reproduction.
Old claims of CURRENT, NEXT, or AUTHORIZED have no present execution authority.

The relocation preserves existing compatibility imports. Some archived modules
are still reached by the demo, older campaign code, replay, or tests; this is
not an independently runnable repository and does not claim zero coupling.
Change these modules only with their consumers and regression tests in scope.

Raw data, manifests, and historical results must remain byte-preserved. New
provider runs require a separately reviewed and owner-authorized experiment.
For current work, start at `docs/ACTIVE_RESEARCH_SURFACE.md` in the repository root.
