## 1. 母问题与论文命题

第一篇回答：在相同的已实现 round-1 状态上，ATTACKS 选择器是否改变最终决策质量。

第二篇只回答一个更实际的问题：

> 在无法读取真值的行动时刻，能否只对“CONTROL 将高置信失败且 ATTACKS 能救援”的状态采取 ATTACKS，并在独立任务上优于固定策略？

社会热力学在这里是一个**可证伪的检测器族**，不是系统本体、物理定律或装饰性叙事。它必须改变 CONTROL/ATTACKS/ESCALATE 的在线选择，并在独立结果上胜过更简单的置信度与分歧基线；否则该构念被拒绝，不追加工程层。

## 2. 论文级贡献候选

若独立确认通过，候选贡献为：

1. 一个只读取行动前状态、从不读取真值的定向救援检测器；
2. 一个把检测准确率转化为实际路由价值的同状态反事实评估；
3. 对社会热力学状态表示的增量价值作直接、可失败的比较，而不是只报告相关性或 AUROC。

若检测器未通过，第一篇仍保持完整可投；第二篇停止，不把负结果硬包装成系统论文。

## 3. 决策、允许输入与独立结果

### 3.1 在线决策

对每个 round-1 状态，策略输出三者之一：

- `CONTROL`：不增加结构化披露；
- `ATTACKS`：披露 attack-labeled 条目；
- `ESCALATE`：当两种已有策略都被预测为高风险时，请求一个真正的新观察或独立人工/模型复核。

第一轮实验只比较 CONTROL 与 ATTACKS；ESCALATE 可以作为带成本的拒答位保留，但除非实验能取得独立新信息，不把 public-only second opinion 称为验证。

### 3.2 允许的在线输入

检测器只能读取 fork 之前已经存在的材料：

- 各 agent 的 round-1 概率向量；
- round-1 transcript；
- 结构化 evidence items、模型自标签和来源 agent；
- 当时可计算的文本相似度、来源覆盖和缺失标志；
- 任务表面的选项数、agent 数和资源成本。

禁止读取：`correctAnswer`、`groundTruth`、resolver 结果、任一 continuation 的最终 Brier、后续人工判断或未来日志。缺失的敏感度或依赖量必须编码为“未知/缺失”，不能写成 0。

### 3.3 离线监督目标与独立结果

真值只在离线训练和评估中使用：

- **失败目标**：`Y_fail = 1[CONTROL round-1/final outcome exceeds the pre-frozen severe-loss threshold]`；
- **个体救援效应**：`tau = Brier_ATTACKS - Brier_CONTROL`，负值表示 ATTACKS 更好；
- **主结果**：路由策略的等任务平均 Brier 与带成本 regret，而不是 detector AUROC；
- **安全结果**：灾难任务召回率、非灾难任务不必要干预率、最坏分位损失；
- **成本结果**：每个避免的灾难所需额外 continuation/复核次数。

阈值、成本和最小值得效应必须在新确认集结果揭盲前冻结。

## 4. 最小社会热力学检测器

只保留三个可在线计算的状态量，每个量都必须有明确决策用途：

| 状态量 | 操作化定义 | 改变的决策 | 失败检验 |
|---|---|---|---|
| `U`：承诺强度 | 群体 pooled belief 的集中度/负熵与最大选项 margin 的预冻结组合 | 高承诺但可能错误时提高风险 | 在 held-out 数据中不改善灾难识别或路由价值 |
| `T`：认知温度 | agent 概率向量的平均成对 Jensen–Shannon divergence 或 TV；二者只选一个 | 高分歧时提高干预或升级倾向 | 不优于单独 confidence/disagreement 基线 |
| `S`：独立信息广度 | 去除近重复后的语义簇覆盖 × 来源覆盖；来源身份不等同统计独立 | 区分“多源重复”与“多样观察” | 与结果无稳定增量关系，或仅反映文本长度 |

预注册一个低自由度复合量：

\[
R_{ST}=z(T)+z(U)-z(S),
\]

其中标准化参数只由训练折得到。这个符号表达的直觉是“高分歧、高承诺、低独立信息广度”更危险；它不是热力学自由能的字面物理同一。若该固定复合量失败，允许比较 `U,T,S` 的正则化逻辑回归，但不通过搜索大量公式追求显著性。

检测器的最终动作规则保持简单：仅当预测 `tau < -delta` 且预测 CONTROL 严重失败概率超过阈值时选择 ATTACKS，否则 CONTROL；无法可靠覆盖的高风险状态进入 ESCALATE/ABSTAIN。

## 5. 必须击败的简单基线

社会热力学检测器至少与以下策略同表比较：

1. 永远 CONTROL；
2. 永远 ATTACKS；
3. pooled confidence/margin 单变量阈值；
4. agent disagreement 单变量阈值；
5. `confidence + disagreement` 的二变量正则化逻辑回归；
6. 随机但匹配干预率的策略。

只有当 `R_ST` 或三变量模型在独立评估中提升**路由后的 proper loss/成本效用**，才能说社会热力学有检测价值。AUROC 更高但政策价值不提高，判定为失败。

## 6. 两阶段最小实验

### 阶段 A：零新增调用的可行性门（探索性）

使用第一篇已有的 45 tasks × 2 seeds 同状态数据，但明确只作开发：

- 外层按 task 分组，严禁同一 task 的两个 seeds 跨训练/测试折；
- 所有阈值、标准化、文本聚类和模型系数只在内层训练折估计；
- 比较固定复合量、三变量模型与简单基线的 out-of-fold 路由价值；
- 做标签置换与特征缺失压力测试；
- 报告每个任务的选择与反事实损失，不只报总体 AUC。

**进入阶段 B 的门槛（DESIGN INTENT，须在运行 A 前冻结数值）：**社会热力学候选必须在嵌套 task-level 评估中同时满足：

- 相对最佳简单 detector 基线具有正的成本调整 policy value；
- 相对 always-CONTROL 降低灾难任务损失，而非主要移动已正确任务；
- 效果不由单个任务、文本长度或 agent 数驱动；
- 选择规则可以在一页伪代码内完整描述。

若任一项失败：停止。允许记录负结果，但不新增 schema、模型或公式。

### 阶段 B：条件触发的独立确认

只有阶段 A 过门后才购买新数据/调用。确认集必须与阶段 A 按任务族隔离，并且在揭盲前冻结：

- 新任务来源与答案键；
- CONTROL/ATTACKS 两臂及相同 round-1 state 的 fork；
- 任务数、seeds、模型版本与 provider 配置；
- 检测器参数、阈值、`delta`、成本函数和失败阈值；
- 主对比、bootstrap 单位和停止规则。

建议先做功效/预算模拟，再选择最小确认规模。默认不保留 SUPPORTS 臂，因为第二篇的行动决策是 CONTROL 对 ATTACKS；只有独立科学问题要求时才增加。每个 task-seed 只运行一次 round 1，然后 fork 两臂，避免为 detector 另建完整运行框架。

独立确认的主分析：

\[
V(\pi)=\frac{1}{N}\sum_t Brier_{\pi(X_t),t}+c_A I[\pi(X_t)=ATTACKS]+c_E I[\pi(X_t)=ESCALATE].
\]

比较预冻结路由策略与 always-CONTROL、always-ATTACKS 和最佳简单 detector。任务是重采样单位。社会热力学候选只有在 policy value 的区间优于最佳简单 detector 且灾难召回不以明显增加非灾难伤害为代价时通过。

阶段 B 复用现有 V6 fork，只把三臂缩成两臂并增加预行动 detector 输出。允许的设施修补仅为：正式 final-report parser、轻量失败码、覆盖全部 fork 输入的 hash、manifest 外文件拒绝。禁止为本论文新增通用路由引擎、事件总线、跨仓库拆分、物理模拟器或新的 schema 层级。

## 8. 预期论文结构

1. **问题**：治理干预是定向救援，不是 universal booster；真正困难的是无真值路由。
2. **检测器**：三维社会热力学状态表示与简单决策规则。
3. **开发证据**：严格 task-grouped 的回顾性可行性，不作确认性升级。
4. **独立确认**：新任务上的同状态两臂反事实 policy evaluation。
5. **实用性**：proper loss、灾难召回、不必要干预和调用成本。
6. **失败边界**：复合量若不胜过简单基线，则社会热力学叙事被证伪。
