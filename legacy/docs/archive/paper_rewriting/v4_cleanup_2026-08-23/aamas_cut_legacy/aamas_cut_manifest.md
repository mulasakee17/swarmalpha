# AAMAS 切片说明

## 唯一主张

未经验证的 LLM 自报概率不应获得多智能体治理权。论文只论证“报告如何取得权限”，不论证平台规模、通用异构治理或社会热力学定律。

## 相对母白皮书的删减

- Q0--Q3 压缩为完整性、测量效度、控制资格三道门；
- 只保留 coverage、JSD、Brier 和 candidate certainty detector；entropy、margin、TV、ECE 细节和完整量注册表不再展开；
- Schema-5、hash、registry 与 lifecycle 压缩为一个 replay 小节；
- 只保留一种 public-only verification 干预及 apply/sham/holdout；
- MCV 与社会热力学各压缩为 Discussion 一段；
- 删除 Web3、信誉、质押、完整治理 scorecard 和平台路线图；
- 结果只保留能检验三项贡献的 80-run evidence。

## 仍需补强

当前仍是中文切片初稿。AAMAS 投稿版需要真实 measurement-validity sealed result、held-out detector validation、足量治理随机实验、英文改写和官方双栏 8 页排版。
